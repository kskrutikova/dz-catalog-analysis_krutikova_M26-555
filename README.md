# Анализ каталога фильмов

Учебный проект на Python для анализа каталога фильмов.

## Запуск 

```powershell
uv run catalog_analysis.py
```

## Проверка качества кода

```powershell
uv run ruff check .
```

## Структура проекта

- `catalog_analysis.py` — основной скрипт с решением задания.
- `pyproject.toml` — настройки проекта и Ruff.
- `uv.lock` — зафиксированные зависимости проекта.
- `.python-version` — закрепленная версия Python 3.12.
- `.gitignore` — список файлов и папок, которые Git не отслеживает.
- `README.md` — описание проекта и команд для работы с ним.
